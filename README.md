# DS Startup Funding Analysis
Startup Funding & Sector Investment Dashboard
## Project Overview
This project focuses on analyzing startup funding data to understand investment patterns across different sectors and cities.
The Project involves:
  ->Cleaning and preprocessing startup funding data using python and regular expressions(Regex).
  ->Performing Exploratory Data Analysis(EDA).
  ->Identifying funding trends across different sectors and cities.
  ->Analyzing startup and investor information.
  ->Developing an interactive dashboard using streamlit.
